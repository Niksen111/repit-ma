# Публичные страницы преподавателей

Один backend обслуживает `repit-ma.ru` (Мария), `okoroleva.repit-ma.ru` (Ольга)
и `mathegor.repit-ma.ru` (Егор). Контент выбирается через `GET /api/public/site`
по заголовку Host. Неизвестные домены возвращают 404.

Главная, вход, кабинет, регистрация и ссылки на API используют относительные
адреса и сохраняют текущий поддомен. Авторизация хранится отдельно для каждого
origin. Доступ к ученикам и курсам определяется аккаунтом и его правами;
публичная страница не создаёт аккаунт преподавателя в базе автоматически
и пока не привязана к числовому ID аккаунта.

## Исходники

- `frontend/src/main.ts` — главная Марии и маршрутизация интерфейса.
- `frontend/src/olga-home.ts` — главная Ольги.
- `frontend/src/egor-home.ts` — главная Егора.
- `frontend/src/teacher-site.ts` — выбор страницы и контакты преподавателей.

## Локальная проверка

Локальная проверка с Vite: `http://localhost:5173` — Мария,
`http://okoroleva.localhost:5173` — Ольга, `http://mathegor.localhost:5173` — Егор.
Эти адреса работают и без запущенного
Java-сервера; при запуске сервера Vite сохраняет Host в прокси-запросе.
Если система не разрешает поддомен `.localhost`, добавить его в hosts как `127.0.0.1`.

## Контент Егора

Контент Егора находится в `frontend/src/egor-home.ts`, контакты — в записи
`egor` файла `frontend/src/teacher-site.ts`. Запись на занятия — через MAX,
Telegram `@eztguser` или почту `zagidulinegor@yandex.ru`.
Фотография находится в `frontend/public/images/egor.png`: оригинал сохранён,
портрет крупнее кадрируется стилями первого экрана. На странице размещены шесть реальных отзывов,
переданных Егором. Оценка 5 из 5 указана только у Елены и Надежды;
тексты сохранены без редактирования, даты и классы авторов не добавлялись.
