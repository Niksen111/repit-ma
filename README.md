# Repit MA

Веб-приложение для совместной работы репетитора и учеников. Проект должен собрать в одном месте расписание занятий, учебный прогресс, домашние задания, материалы и учет оплат.

> Проект находится на ранней стадии: сейчас в репозитории есть базовый Spring Boot-каркас и черновик пользовательских сценариев.

## Возможности

В рамках первой версии планируются:

- кабинеты репетитора и ученика с разграничением доступа;
- регистрация ученика по ссылке-приглашению от репетитора;
- общее расписание с датами занятий и темами уроков;
- история занятий, оценки и отслеживание прогресса;
- выдача и сдача домашних заданий, включая загрузку файлов и фотографий;
- справочные и учебные материалы;
- учет оплат с подтверждением со стороны репетитора и напоминаниями о задолженности;
- отдельные разделы для пробных работ и результатов подготовки.

Исходный набросок интерфейсов и требований находится в [doc/repit-ma-doc.drawio](doc/repit-ma-doc.drawio). Открыть его можно в [diagrams.net](https://app.diagrams.net/).

## Запуск

Для локальной работы потребуются JDK 21 и Git. Gradle отдельно устанавливать не нужно: в проекте есть Gradle Wrapper.

Клонируйте репозиторий и перейдите в его каталог, затем запустите приложение:

```bash
./gradlew bootRun
```

В Windows PowerShell:

```powershell
.\gradlew.bat bootRun
```

Сейчас `compose.yaml` не содержит сервисов. Если Spring Boot попытается запустить Docker Compose, временно отключите интеграцию:

```powershell
.\gradlew.bat bootRun --args="--spring.docker.compose.enabled=false"
```

После запуска приложение будет доступно по адресу `http://localhost:8080`.
